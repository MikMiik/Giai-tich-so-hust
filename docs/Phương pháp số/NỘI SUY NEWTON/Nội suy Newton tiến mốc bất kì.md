
- **Đầu vào:** Bậc $n \in \mathbb{N}$; mảng $X = [x_0, x_1, \dots, x_n]$, $Y = [y_0, y_1, \dots, y_n]$ với các $x_i$ đôi một khác nhau.
    
- **Các bước thực hiện:**
    
    1. **Tính vector tỷ sai phân $C$:**
        
        - Đặt $c_i = y_i$ với $i = 0, 1, \dots, n$.
            
        - Lặp $j = 1, 2, \dots, n$:
            
            - Lặp $i = n, n - 1, \dots, j$:
                
                $$c_i = \frac{c_i - c_{i-1}}{x_i - x_{i-j}}$$
                
        - Thu được vector $C = [c_0, c_1, \dots, c_n]$.
            
    2. **Tạo ma trận đa thức cơ sở $A$ (kích thước $(n+1) \times (n+1)$):**
        
        - Khởi tạo hàng 0: $A_0 = [0, 0, \dots, 0, 1]$.
            
        - Lặp $k = 1, 2, \dots, n$ (ứng với $x_{k-1}$):
            
            - Với $i = n, n - 1, \dots, 0$:
                $$A_{k, i} = A_{k-1, i+1} - x_{k-1} \cdot A_{k-1, i} \quad \text{(quy ước } A_{k-1, n+1} = 0\text{)}$$
                
    3. **Tính mảng hệ số kết quả $P = C \cdot A$:**
        
        - Với mỗi chỉ số cột $j = 0, 1, \dots, n$ (tương ứng bậc $x^{n-j}$):
            $$P_j = \sum_{k=0}^n C_k \cdot A_{k, j}$$
            
- **Đầu ra:** Mảng hệ số chính tắc $P = [P_0, P_1, \dots, P_n]$ đại diện cho $P_n(x) = \sum_{j=0}^n P_j x^{n-j}$.

### VD

- **Đầu vào:**
	- $n = 5$
	- $X = [1.2, \quad 1.5, \quad 1.7, \quad 1.9, \quad 2.1, \quad 2.4]$

- **Các bước:**
    1. Bảng tỷ sai phân:

        - $k = 1$ ($x_0 = 1.2$): $A_1 = [0, 0, 0, 0, 1, -1.2]$

    3. **Tính $P = C \cdot A$:** Thực hiện nhân vô hướng vector $C$ với từng cột của ma trận $A$ (từ bậc $x^5$ giảm dần đến $x^0$):

        - $P_3 = \sum C_k \cdot A_{k,3} = \mathbf{-1.0229}$
            
        - $P_4 = \sum C_k \cdot A_{k,4} = \mathbf{0.0506}$
            
        - $P_5 = \sum C_k \cdot A_{k,5} = \mathbf{1.9762}$
            
- **Đầu ra:** Mảng hệ số chính tắc $P = [-0.0152, 0.1170, -0.0254, -1.0229, 0.0506, 1.9762]$ tương ứng với đa thức hoàn chỉnh:
    $$P_5(x) = -0.0152x^5 + 0.1170x^4 - 0.0254x^3 - 1.0229x^2 + 0.0506x + 1.9762$$
